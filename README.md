# Power BI Supermarket Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze supermarket sales, profitability, product categories and store performance.

The dashboard was created as part of a Data Analytics project and focuses on transforming raw business data into meaningful insights through interactive visualizations and KPIs.

## Objectives

- Analyze sales and revenue performance
- Evaluate profitability and margins
- Compare product categories
- Analyze store performance
- Identify key business trends and patterns

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## Dashboard

The dashboard includes interactive pages covering:

- Sales Overview
- Product & Category Analysis
- Store Performance

## Key Features

- Interactive filters and slicers
- KPI cards
- Category-level analysis
- Store performance comparisons
- Top-N analysis
- DAX-based calculations
- Interactive data visualizations

## Files

The repository contains the Power BI report and supporting dashboard screenshots.
